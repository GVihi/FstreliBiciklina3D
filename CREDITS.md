# Credits

This file lists everything in FstreliBiciklina3D that was not made by the project's own author, plus the notes the in-game credits screen (Milestone E) will be generated from.

## The rule

**Every third-party asset gets an entry in this file in the same commit that adds it.** That covers models, textures, fonts, sounds, music, icons, code and anything else that came from somewhere else.

1. One entry per file or pack, written when the file is added, not later.
2. Check the licence on the asset's own page first. Licences change and sites differ. Do not trust a general list. Where the licence comes from is described in [`docs/ASSET_SOURCES.md`](docs/ASSET_SOURCES.md).
3. Do not add a file with an unclear or non-commercial licence "for now" (CC-BY-NC, non-commercial-only libraries and similar are not allowed).
4. Keep the original download (zip or page link) noted in the entry, in case a licence ever needs proving.
5. If the licence requires credit (CC-BY and others), the entry must contain the exact credit text, the licence name and a link to it, and a note of any changes made.
6. If a third-party asset is removed from the project, move its entry to "Removed assets" at the bottom rather than deleting it.

### Entry template

Copy this under the right heading:

```
### <asset or pack name>
- Used for: <where it is used in the game, with file paths>
- Author: <name or studio>
- Source: <page URL>
- Licence: <name, with link to the licence text>
- Retrieved: <YYYY-MM-DD>
- Changes: <none, or what was changed>
- Credit text: <the exact line to show, or "none required">
```

## Made for this project

These are the project's own work and need no third-party credit:

- **Code and data:** everything under `scripts/`, `data/`, `tools/` and `main.tscn`.
- **3D models:** built as Python scripts for Blender (`bpy`) in `tools/models/`, exported to `assets/models/`. Written with Claude (Anthropic) as the modeller, and checked in the game by the owner.
- **Synthesised sound effects:** the WAV files in `audio/` generated by `tools/bake_audio.py`, which re-implements the recipes of the original WebAudio version of the game. They are planned to be replaced (see the Sound section of the roadmap).
- **Voice lines:** the spoken lines in `audio/voice/` are the owner's own recordings. Text for each line is in `audio/voice/VOICE_LINES.txt`.
  - Who recorded each line is **not noted yet** (roadmap item S6: "Note who recorded each line"). Add the names here when known.

## Engine and tools

- **Godot Engine**: <https://godotengine.org>. MIT licence. The licence requires its copyright notice to ship with the game. Add the notice text here, or link to Godot's own licence screen in the credits, before release.
